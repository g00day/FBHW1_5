# Итоговая работа №1: Разработка Frontend и Backend

В рамках первой контрольной работы было выполнено 5 практических заданий:

- **ПР №1:** Разработан пользовательский интерфейс с использованием препроцессоров SASS и LESS. Создано визуальное отображение карточек товаров, позволяющее пользователю получить наглядное представление о продукте и его основных характеристиках.

- **ПР №2:** Создан базовый сервер на Node.js с набором эндпоинтов, реализующих принципы CRUD (создание, чтение, обновление, удаление). Это основа для последующего создания маршрутизатора и полноценного API для взаимодействия клиентской части с серверными данными.

- **ПР №3:** Освоена работа с Postman для тестирования серверных запросов и анализа ответов. Изучены принципы отправки запросов к серверу, структура получаемых ответов, а также взаимодействие с различными внешними API для получения полезных пользователю данных.

- **ПР №4:** Реализован полноценный веб-сайт с клиентской и серверной частями, работающими на разных HTTP-портах. Использованы Express JS и React JS совместно с RESTful API для обеспечения возможности удаления, редактирования и обновления информации о товарах.

- **ПР №5:** Подготовлена спецификация OpenAPI с помощью Swagger, документация доступна по адресу `http://localhost:3000/api-docs/`. Это позволяет разработчикам быстро ознакомиться с API благодаря понятному и структурированному описанию.

## Результат первой контрольной работы: Интернет-магазин рыболовных снастей

Итогом первой контрольной работы стал функционирующий веб-сайт с возможностью добавления, удаления и редактирования товаров для рыбалки, оснащенный документированным API и удобным пользовательским интерфейсом.

- **Использование препроцессора less**  
В финальной версии приложения в фронтенд-приложении(клиенте) используется препроцессор less для вынесения глобальных стилей оформления карточки товара в переменные: цвета злементов, цвета шрифта, углы скругления разных ui-элементов. Вынесение переиспользуемых стилей в миксины


- **Использование Express.js**
Express.js используется для создания программного интерфейса для клиентской части приложения: реализация интерфейсов для взаимодействия клиентского приложения с сервером(endpoints), хранение данных(имитация структурированной бд через использование js-списка), управление внешним доступом(создание CORS-политики)

- **Postman как клиент для тестирования API**
В рамках разработки сайта использовался http-клиент postman, c помощью него производилось тестирование работоспособности конечных точек API с разными request data и http-методами

- **Использование React.js + Vite**
Для создания пользовательского клиента был использован react.js, с его помощью был создан понятный для человека пользовательский интерфейс для взаимодействия с карточками товаров. Vite использовался как инструмент для билда и запуска фронтенд-приложения

- **Swagger docs**
Дополнительно была создана swagger ui спецификаця для создания пользовательского интерфейса для документорования и тестирования API
